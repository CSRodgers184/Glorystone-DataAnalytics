## Approach
Every project follows the same structure:
1. Clear business question
2. Real (or realistically simulated) operational data
3. Cleaning + feature engineering
4. Analysis focused on decision-relevant metrics
5. Visualizations that support the diagnosis
6. Specific, prioritized recommendations

This repository is the public evidence of capability as a Domain Specialist who can turn operational data into actionable recommendations.
